# Examples

## Ví dụ 1: Hỏi tips chung
**Input:** "Cho mình vài tips dùng Claude Code hiệu quả"
**Output:**
Đây là 5 tips quan trọng nhất:

1. **Luôn dùng plan mode** — bắt đầu bằng "hãy lên kế hoạch trước", Claude sẽ phỏng vấn rồi mới code
2. **CLAUDE.md ≤ 200 dòng** — dài quá Claude sẽ bỏ qua. Tách chi tiết ra `.claude/rules/`
3. **Manual /compact ở 50%** — đừng để context đầy, Claude sẽ "ngu" đi
4. **Esc Esc khi lệch hướng** — đừng cố sửa trong cùng context, rewind rẻ hơn
5. **Commit mỗi giờ** — task xong = commit luôn

📚 Gõ `/best-practices` để tra cứu theo category.

## Ví dụ 2: Hỏi về orchestration
**Input:** "Command agent skill pattern là gì?"
**Output:**
Pattern **Command → Agent → Skill** là kiến trúc phân tầng:

```
User → /command (entry point, orchestrator)
         ├→ Agent (data fetching, có preloaded skills)
         └→ Skill (output generation, chạy độc lập)
```

**2 loại Skill:**
- **Agent Skill** (preloaded): inject vào agent context khi startup, agent dùng như domain knowledge
- **Skill** (direct): command gọi trực tiếp qua Skill tool

**Ví dụ thực tế:**
```
/weather-orchestrator (command)
  ├→ weather-agent (agent, preloaded: weather-fetcher)
  │   └ weather-fetcher (skill, domain knowledge)
  └→ weather-svg-creator (skill, tạo SVG output)
```
